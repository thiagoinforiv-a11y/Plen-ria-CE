# Plen-ria-CE
## Bloco da Barragem — landing page

`index.html` é a página de apresentação do projeto (arquivo único, funciona offline).

Para preencher:
- Campos entre `[COLCHETES]` no texto (público estimado, valor movimentado, fotos, vídeo, perfil, grupo, comissão).
- No fim do arquivo, no bloco `CONFIG`: número do WhatsApp e data do evento (contagem regressiva).
